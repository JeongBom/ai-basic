자연어 처리란 무엇일까?

114쪽

기계가 사람의 언어를 이해하고 생성하며 인간과 상호 작용하는 기술이다.

자연어
사람들이 평소 사용하는 언어로, 주로 텍스트나 음성으로 이루어진 비정형 데이터이다.

자연어 처리(NLP: Natural Language Processing)는 인간이 사용하는 언어를 기계가 이해하고 처리할 수 있도록 하는 인공지능의 한 분야로 1950년대부터 연구가 이루어졌다. 자연어 처리는 와 으로 나눌 수 있다.

언어 이해
기계가 인간의 언어를 이해하도록 만드는 방법과 과정을 의미하며 문장에서 의미를 파악하는 능력이 필요하다.
언어 생성
기계가 인간이 이해할 수 있는 자연스러운 언어를 생성하는 방법과 과정을 의미한다. 이는 문장 구조에 따라 적절한 단어와 문법을 선택하는 것을 포함한다.

자연어 처리의 활용 분야는 언어 이해와 언어 생성 중 한 가지로 명확히 구분하기 어렵다. 그림은 더 강조되는 부분이 무엇인지를 생각해서 표시한 것이다.

자연어 처리의 목표는 기계가 인간의 언어를 이해하고 상호 작용하며 자연어를 이용해 여러 가지 문제를 해결하는 것이다.

🤔 번역은 왜 그림의 가운데(둘 다)에 있을까?

생각한 뒤 눌러서 답 확인
번역은 먼저 원래 문장의 의미를 파악해야 하고(언어 이해), 그다음 다른 언어로 자연스러운 문장을 만들어야 한다(언어 생성). 두 과정이 모두 필요해서 가운데에 있다. 챗봇과 생성형 언어 모델도 마찬가지다.

챗봇은 어떻게 대답할까?

114쪽

“근처 맛집 추천해 줘.”라고 말하면 음성 챗봇은 다음 과정을 거쳐 대답한다.

🗣 음성→→텍스트 문서로 전환→→의미와 의도 분석→검색→→검색을 기반으로 문장 생성→→🔊 음성
단계하는 일챗봇의 속마음
음성 인식말소리를 텍스트 문서로 전환한다“근처 맛집 추천해 줘.”
언어 이해텍스트의 의미와 의도를 분석한다“음식점 추천을 원하는 거구나.”
검색필요한 정보를 인터넷에서 검색한다“사용자 근처의 음식 정보를 검색해야지.”
언어 생성검색 결과를 바탕으로 문장을 만든다“현재 ○○ 위치의 □□ 음식점이 ◇◇ 음식으로 좋은 평가를 받고 있습니다.”
음성 합성텍스트를 음성으로 변환하여 대답한다🔊

🤔 지난 시간에 배운 음성 인식은 이 과정에서 어디에 들어 있을까? 자연어 처리는?

생각한 뒤 눌러서 답 확인
음성 인식은 말소리를 텍스트로 바꾸는 첫 단계이고, 마지막의 음성 합성은 텍스트를 다시 말소리로 바꾼다. 그 사이의 언어 이해와 언어 생성이 자연어 처리이다. 지난 시간에 “듣는 과정은 음성 인식, 이해하여 대답을 떠올리는 과정은 자연어 처리”라고 배운 것과 같다.

🤔 글자로 대화하는 텍스트 챗봇에는 이 다섯 단계가 모두 필요할까?

생각한 뒤 눌러서 답 확인
아니다. 텍스트 챗봇은 말소리를 다루지 않으므로 음성 인식과 음성 합성이 필요 없다. 언어 이해 → 검색 → 언어 생성만 있으면 된다.

인공지능은 텍스트 데이터를 어떻게 인식할까?

115쪽

텍스트 데이터를 숫자로 변환하여 인식한다.

텍스트 데이터를 숫자로 변환하는 것은 인공지능이 텍스트 데이터를 이해하고 처리하기 위한 핵심 단계이다. 인공지능은 숫자를 이용해 텍스트 데이터에서 유용한 특징을 추출할 수 있고, 기계학습 알고리즘을 파악해 다양한 분석을 수행할 수 있다.

텍스트를 숫자로 변환하는 일반적인 방법은 단어의 , , 이 있다. 원-핫 인코딩은 단어를 나타내는 고정 길이 벡터에서 해당 단어만 1로 표현하는 방법이다. 워드 임베딩은 0과 1만 표현하는 원-핫 인코딩의 한계를 극복한 방법으로, 학습을 통해 단어를 저차원의 실숫값으로 변환하는 방법을 사용함으로써 단어 간의 관계와 의미를 파악할 수 있게 해 준다.

표Ⅱ-11 문장을 띄어쓰기 기준으로 분리 후 숫자로 변환한 예시. 단어가 6개이므로 원-핫 인코딩의 고정 길이는 6이 된다.

원-핫 인코딩
해당 단어만 1을 표시하고 나머지는 0으로 만들어 1에만 단어에 대한 정보가 들어 있다. 이를 희소 표현(sparse representation)이라고 한다. 단어의 개수가 증가함에 따라 불필요한 공간이 늘어나는 단점이 있다.
(1, 0, 0, 0, 0, 0): 6차원
워드 임베딩
(0.2, 0.4)와 같이 원-핫 인코딩보다 차원이 줄고 정보를 실숫값으로 나누어 표현하여 밀집 표현(dense representation)이라는 용어를 사용한다.
(0.2, 0.4): 2차원

🤔 단어가 5만 개인 사전으로 원-핫 인코딩을 하면 벡터 하나의 길이는? 그중 1은 몇 개일까?

생각한 뒤 눌러서 답 확인
길이는 50,000이고 그중 1은 단 1개, 나머지 49,999개는 0이다. 단어의 개수가 증가함에 따라 불필요한 공간이 늘어나는 것이 원-핫 인코딩(희소 표현)의 단점이다. 워드 임베딩은 이것을 수십~수백 개의 실숫값으로 줄인다.

워드 임베딩 — 단어를 벡터 공간의 점으로

115쪽

임베딩을 통해 생성된 단어 벡터는 각각의 단어가 가지는 의미를 벡터 공간에 각 점으로 표현하는데, 이렇게 임베딩된 벡터들은 다양한 딥러닝 모델에 으로 사용될 수 있다. 임베딩을 사용한 딥러닝 모델은 텍스트 데이터를 더 효과적으로 이해하고 더 정확하게 예측한다.

워드 임베딩의 특징
  • 비슷한 의미를 가진 단어가 서로 가까운 곳에 위치하도록 학습된다.
  • 단어 간 의미가 있으므로 단어의 연산(+, −)을 하면 의미 있는 다른 단어가 나온다.

🤔 워드 임베딩의 숫자(0.2, 0.4 같은 값)는 누가 정할까?

생각한 뒤 눌러서 답 확인
사람이 정하지 않는다. 워드 임베딩은 원-핫 인코딩을 딥러닝으로 학습하여 만든다. 문장에서 단어 벡터를 표현하여 의미를 이해할 수 있도록 학습하고, 그 결과 비슷한 의미의 단어가 가까운 곳에 놓인다.

🤔 “고양이”와 “강아지”의 벡터가 가깝다는 것은 무슨 뜻일까?

생각한 뒤 눌러서 답 확인
두 단어의 의미가 비슷하다는 뜻이다. 임베딩은 단어의 의미를 벡터 공간의 점으로 표현하므로, 점 사이의 거리가 가까우면 단어 간의 관계와 의미가 비슷하다고 본다. 원-핫 인코딩에서는 모든 단어가 똑같이 멀어서 이런 관계를 알 수 없다.

언어 이해 ① 빈도수 기반 방식

116쪽

인공지능에서 언어 이해란 텍스트나 음성으로 제시된 정보를 인식하고 이해하는 것이다.

인공지능에서 언어 이해란 사람이 언어를 이해하는 방식을 모방하여 텍스트나 음성으로 제시된 정보를 인식하고 이해하는 것을 의미한다. 이는 단순히 단어나 문장을 인식하는 것뿐만 아니라 그 내용이 가진 의미와 문맥, 그리고 의도를 파악하는 것을 포함한다.

빈도수 기반 방식은 단어나 문장이 텍스트 데이터 내에서 를 세는 방식으로, 자연어 처리에서 사용하는 쉽고 간단한 방법이다. 이 방식은 단어의 순서나 의미 등을 무시하고 단어의 출현 빈도만을 고려하여 주요 언어를 이해한다.

단어 주머니(bag of words)
빈도수 기반 방식에서는 문서나 텍스트 데이터의 단어가 순서나 문맥, 구문 등을 무시하고 오직 빈도수만 고려한다. 이는 마치 주머니에 섞여 있는 것처럼 처리되어 단어 주머니라는 이름이 붙었다.
배우공연가수투자성장경제기업선수경기팀승리기사 분류
문서 1107522000000연예
문서 202256772100경제

표Ⅱ-12 단어의 빈도수를 이용한 뉴스 기사 분류. 문서 1은 배우, 공연, 가수의 빈도수가 높아서 ‘연예’ 기사로 분류되었다. 문서 2, 문서 3도 같은 원리로 각각 ‘경제’, ‘스포츠’ 기사로 분류되었다.

🧪 해 보기 — 단어 주머니로 분류하기 문장을 넣고 분류를 누르면 세 주머니의 단어가 몇 번 나오는지 세어 가장 많은 쪽으로 분류한다.

“경기장에 가수가 와서 공연을 했다”처럼 두 주머니의 단어가 섞인 문장도 넣어 보자. 단어 순서를 바꿔 넣어도 결과가 같은지 확인해 보자.

🤔 단어 주머니 방식은 “나는 너를 사랑해”와 “너는 나를 사랑해”를 구별할 수 있을까?

생각한 뒤 눌러서 답 확인
구별하지 못한다. 단어 주머니는 단어의 순서를 무시하고 어떤 단어가 몇 번 있는지만 세기 때문에 두 문장은 똑같은 주머니가 된다. 이것이 빈도수 기반 방식의 한계이고, 뒤에서 배울 순환 신경망이 필요한 이유이다.

스스로 해결하기 — 워드 클라우드 만들기

116쪽

코랩에서 글의 단어 빈도수를 세어 워드 클라우드를 만들어 보고, 빈도수 기반 방식의 장단점을 생각해 보자.

워드 클라우드는 자주 나온 단어일수록 글자를 크게 그린 그림이다. 단어의 빈도수만 세어서 만들기 때문에 빈도수 기반 방식 그 자체이다.

① 라이브러리·한글 글꼴 준비→② 글 붙여 넣기→③ 단어 빈도수 세기→④ 워드 클라우드 그리기
  1. 코랩 노트북을 열고 ①번 셀을 실행한다. 한글 글꼴을 설치하느라 30초쯤 걸린다.
  2. ②번 셀을 실행하면 입력 칸이 나온다. 뉴스 기사, 노래 가사 등 분석할 글을 붙여 넣고 Enter를 누른다.
  3. ③④번 셀의 빈칸을 채우고 실행한다.
📋 붙여 넣을 글이 없다면 오늘 배운 내용을 정리한 글이다. 복사를 누른 뒤 코랩 ②번 셀의 입력 칸에 붙여 넣자.
🎯 이 코드는 무엇을 할까?

글에 나온 단어마다 인덱스(고유한 값)를 붙이고 몇 번 나왔는지 센다. 순서와 의미는 무시하고 빈도수만 세는 단어 주머니이다.

코드 셀 ③
# ③ 단어 빈도수 세기
from sklearn.feature_extraction.text import CountVectorizer
corpus = [text]
vector = ()
counts = vector.fit_transform(corpus).toarray()   # 각 단어의 빈도수를 기록한다
print(counts)                                     # 단어 주머니 (빈도수 배열)
print(vector.vocabulary_)                         # 각 단어에 부여된 인덱스

# 많이 나온 단어 10개
words = vector.get_feature_names_out()
freq = sorted(zip(words, counts[0]), key = lambda x: -x[1])
for w, n in freq[:10]:
  print(w, n)

언어 이해 ② 의미론적 접근 방식

117쪽

빈도수 기반의 방식은 단어의 출현 빈도수만 고려하기 때문에 단어가 문장 내에서 어떻게 사용되는지 또는 문장의 전체적인 의미는 무엇인지 등을 알기 어렵다. 인공지능이 인간의 언어를 더 깊이 이해하기 위해서는 , , , 등의 과정을 거쳐야 한다.

1단계 형태소 분석

  • 형태소 분석은 문장을 형태소로 분리하는 과정이다.
  • 각 단어의 본질적인 의미를 이해하려고 한다. 문장을 분리하는 과정에서 단어에 붙은 조사나 접미사 등을 분리하여 단어의 기본 형태를 파악한다.

문장 The small dog quickly ran home to his owner.
방법 The / small / dog / quickly / ran / home / to / his / owner / .

2단계 구문 분석

  • 단어들 사이의 문법적 관계를 파악한다.
  • 문장 내에서 각 단어의 역할과 단어들 간의 관계를 이해하려고 한다. 문장의 구조를 이해하는 게 중요하며 종종 구문 트리를 사용하여 이를 시각화한다.

3단계 의미·개체명 분석

  • 의미 분석은 문장에서 각 단어와 구문의 의미를 분석하는데, 단어의 의미, 단어 조합에 따른 의미 변화를 파악하려고 한다. 예) 사과를 먹는다(O), 기차를 먹는다(X)
  • 개체명 분석은 개체명(Entities)인 사람, 장소, 기관, 숫자, 이벤트 등을 파악하며 단어의 의미를 이해하려고 노력한다. 예) 영수(사람)는 서울(장소)에 3번(숫자) 간 적이 있다.

4단계 담화·의도 분석

담화란 여러 문장을 의미하며 담화·의도 분석은 주어진 텍스트에서 전체 대화의 맥락을 고려하여 문장의 의도를 파악한다. 단순히 개별 단어나 문장의 의미를 넘어서 전체적인 의도와 요청을 이해하려고 노력한다.

🧪 해 보기 — 개체명 분석 단어를 누를 때마다 없음 → 사람 → 장소 → 숫자 순서로 바뀐다. 다 정한 뒤 확인을 누르자.
🧪 해 보기 — 의미 분석 말이 되는 문장이면 O, 안 되면 X.

🤔 “사과를 먹는다”는 되고 “기차를 먹는다”는 안 된다는 것을 인공지능은 어떻게 알까?

생각한 뒤 눌러서 답 확인
의미 분석 단계에서 단어의 의미와 단어 조합에 따른 의미 변화를 파악하기 때문이다. ‘먹는다’와 함께 올 수 있는 단어가 무엇인지를 알아야 하므로, 단어를 세기만 하는 빈도수 기반 방식으로는 할 수 없다.

언어 이해 ③ 딥러닝을 이용한 방식 — 순환 신경망

118쪽

인공지능이 사람의 언어를 이해하려면 를 기억하는 기능이 필수적이다. 예를 들어, “나는 너를 사랑해.”와 “너는 나를 사랑해.”는 단어 순서에 따라 서로 다른 의미를 갖게 되므로 텍스트 데이터는 입력의 순서가 중요하다. 이처럼 언어를 이해하거나 생성할 때는 단어들의 배열 순서가 중요하지만 대부분의 딥러닝 모델은 이러한 순서를 고려하지 않는다. 예를 들어, 고양이 사진 100장을 넣어 ‘고양이’라는 결과를 출력하는 모델이 있다면 사진 100장이 어떤 순서로 입력되었는지는 중요하지 않다.

이런 언어 이해의 한계를 극복하기 위해 (RNN: Recurrent Neural Network)이라는 모델이 등장했다. 순환 신경망은 이전의 정보를 기억하면서 현재의 입력을 처리한다. 이러한 특성 때문에 순환 신경망은 시간의 흐름에 따라 변하는 데이터를 효과적으로 처리할 수 있다.

🧪 해 보기 — 한 단어씩 넣어 보기 “너는 노래를 못 부르지 않아”를 한 단어씩 넣으면서 두 모델이 어떻게 다르게 판단하는지 보자.

일반적인 딥러닝 — 단어마다 따로 판단한다

순환 신경망 — 앞의 단어를 기억하면서 판단한다

일반적인 딥러닝은 단어마다 따로 판단하므로 ‘못’, ‘않아’가 있는 이 문장을 ‘부정’으로 판단한다. 순환 신경망은 은닉층을 연결하여 이전의 입력값을 기억하므로 ‘긍정’으로 판단한다.

순환 신경망 이후 딥러닝 모델의 성능은 점차 향상되었고, 이를 바탕으로 자연어 처리 기술은 혁신적으로 발전하게 되었다.

🤔 고양이 사진 분류에서는 순서가 중요하지 않은데, 왜 글에서는 순서가 중요할까?

생각한 뒤 눌러서 답 확인
사진 100장은 어떤 순서로 넣어도 각각 ‘고양이’이지만, 글은 단어 순서에 따라 의미가 달라진다. “나는 너를 사랑해”와 “너는 나를 사랑해”는 같은 단어로 이루어졌지만 뜻이 다르다. 그래서 이전의 정보를 기억하면서 현재의 입력을 처리하는 순환 신경망이 필요하다.

생성형 언어 모델이란 무엇일까?

119쪽

주어진 문맥이나 입력에 대해 자연스러운 텍스트를 생성하는 인공지능 기술이다.

생성형 언어 모델(GLM: Generative Language Model)은 패턴 이해를 통해 자연스럽고 의미 있는 텍스트를 생성할 수 있다. 패턴을 이해한다는 것은 다음에 나타날 단어의 을 계산하고 예측하는 것을 의미한다. 빈도수 기반으로 쉽게 이해해 보면 ‘밥’ 다음에는 ‘먹다’, ‘버스’ 다음에는 ‘타다’와 같은 단어들이 자주 등장하는 패턴을 학습한다면 이를 통해 확률적으로 다음에 등장할 단어를 생성해 낼 수 있다.

먹다타다마시다
밥350010
버스02000
커피505400

표Ⅱ-13 단어의 빈도수를 이용한 패턴의 예시

앞서 배운 임베딩은 문맥에서 단어들의 관계와 의미를 추론할 수 있으므로 실제 생성형 언어 모델에서 많이 사용되는데, 문장 생성 방법은 다음과 같다.

→→언어 모델→

따라서 생성형 언어 모델은 언어의 패턴을 익히고, 다음과 같이 확률적으로 다음에 등장할 단어를 예측하여 생성해 낼 수 있다.

🧪 해 보기 — 다음 단어 예측기 후보를 직접 고르거나 확률대로 뽑기를 눌러 문장을 완성해 보자.
🧪 해 보기 — 내 글로 언어 모델 만들기 아래 글에서 “어떤 단어 다음에 어떤 단어가 몇 번 왔는지”를 세어 작은 언어 모델을 만든다. 글을 바꿔 넣으면 모델도 바뀐다.

글이 많아질수록 후보가 다양해지고 확률이 정교해진다. 챗GPT 같은 대형 언어 모델(LLM)은 매우 큰 규모의 텍스트 데이터를 학습하여 같은 원리로 다음 단어를 고른다.

생성형 언어 모델의 활용
챗봇, 기계 번역, 요약, 문장 완성 등 다양한 언어 관련 작업에 활용된다.
대형 언어 모델(LLM)
대형 언어 모델(LLM: Large Language Model)은 매우 큰 규모의 텍스트 데이터를 학습하여 사용된 언어 모델이다.

🤔 “세훈이는 우유를” 다음에 ‘탄다’(20%)가 뽑힐 수도 있다. 이상한 문장이 나오지 않게 하려면?

생각한 뒤 눌러서 답 확인
확률이 높은 단어를 고르면 된다. ‘우유를’ 다음에는 ‘마신다’(60%)가 가장 자연스럽다. 마찬가지로 ‘세훈이는 커피를’을 골랐다면 표Ⅱ-13에서 ‘커피’ 다음에 ‘마시다’가 400번으로 가장 많으므로 ‘마신다’를 붙이는 것이 자연스러운 문장이 된다.

🤔 생성형 언어 모델이 쓰는 확률은 어디에서 올까?

생각한 뒤 눌러서 답 확인
많은 글에서 ‘밥’ 다음에 ‘먹다’가 350번, ‘타다’가 0번처럼 단어들이 자주 등장하는 패턴을 학습한 결과이다. 챗GPT 같은 실제 모델은 단순히 빈도수만 쓰지는 않지만, 큰 흐름은 같다.

확인 문제

114~119쪽

모든 문제의 답을 고른 뒤 채점하기를 누르세요.

1. 자연어 처리는 크게 무엇과 무엇으로 나눌 수 있는가?

자연어 처리는 언어 이해와 언어 생성으로 나눌 수 있다.

2. 다음 중 언어 생성 쪽에 가까운 분야는?

스토리 생성, 자동 완성, 캡션 생성은 언어 생성. 감정 분석, 구문 분석, 텍스트 분류, 상식 추론은 언어 이해.

3. 음성 챗봇이 대답하는 과정의 순서로 옳은 것은?

말소리를 텍스트로(음성 인식) → 의미·의도 분석(언어 이해) → 검색 → 문장 생성(언어 생성) → 텍스트를 음성으로(음성 합성).

4. 텍스트를 숫자로 변환하는 방법이 아닌 것은?

합성곱은 컴퓨터 비전(CNN)에서 이미지의 특징을 뽑는 연산이다.

5. 단어 8개로 이루어진 문장을 원-핫 인코딩하면 단어 하나의 벡터 길이는?

원-핫 인코딩의 고정 길이는 단어의 개수와 같다. 단어가 8개이므로 길이는 8.

6. 원-핫 인코딩을 희소 표현이라고 부르는 이유는?

1에만 단어 정보가 들어 있고 나머지는 0이라 희소(sparse)하다. 단어가 늘수록 불필요한 공간이 늘어난다.

7. 워드 임베딩에 대한 설명으로 옳은 것은?

워드 임베딩은 원-핫 인코딩의 한계를 극복한 밀집 표현으로, 비슷한 의미의 단어가 가까이 놓인다.

8. 빈도수 기반 방식(단어 주머니)이 무시하는 것은?

단어 주머니는 순서나 문맥, 구문을 무시하고 오직 빈도수만 고려한다.

9. “영수(사람)는 서울(장소)에 3번(숫자) 간 적이 있다”처럼 단어가 무엇을 나타내는지 파악하는 분석은?

개체명 분석은 사람, 장소, 기관, 숫자, 이벤트 등 개체명을 파악한다.

10. 순환 신경망(RNN)이 언어 이해에 필요한 이유는?

“나는 너를 사랑해”와 “너는 나를 사랑해”처럼 텍스트는 순서가 중요하다. 순환 신경망은 이전 입력값을 기억한다.

11. 생성형 언어 모델이 문장을 만드는 원리는?

패턴을 학습하여 다음에 등장할 단어를 확률적으로 예측하고, 이를 반복하여 문장을 완성한다.
