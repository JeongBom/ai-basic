컴퓨터 비전 — 교사용 핵심 설명

2-2-2 · 교과서 102~109쪽 · 학생은 스스로 학습 페이지로 공부하고, 교사는 아래 항목만 짚어 준다.

2. 교사가 꼭 설명할 핵심

① 이미지는 숫자 표다 (102쪽)

이렇게 말한다 흑백은 픽셀마다 밝기 값 하나(0 검정 ~ 255 흰색), 컬러는 픽셀마다 R·G·B 세 값. 그래서 흑백 28×28은 784개, 같은 크기 컬러는 3배인 2,352개.
헷갈리는 점 "255는 흰색"(흑백)과 "(255, 255, 255)는 흰색"(컬러)은 둘 다 맞다. 흑백은 세 값이 모두 같은 컬러라고 보면 된다. 지난 시간 교과서 97쪽 그림에서 글씨(255)가 검게 보인 것은 cmap='Greys'가 큰 값을 어둡게 칠하기 때문이지 데이터가 바뀐 게 아니다.

② 컴퓨터 비전 4분야는 두 가지 기준으로 나뉜다 (102쪽)

이렇게 말한다 객체가 하나냐 여럿이냐, 결과가 이름표만 · 상자 · 픽셀 단위냐. 이미지 분류(하나, 이름표) / 객체 위치 식별(하나, 상자) / 객체 탐지(여럿, 상자) / 이미지 분할(여럿, 픽셀). 지난 시간 손 글씨 분류 = 이미지 분류.

③ 왜 새로운 신경망이 필요한가 (104쪽)

이렇게 말한다 지난 시간 모델은 28×28을 784개 한 줄로 펼쳤다 → 위아래로 붙어 있던 픽셀이 멀어져 2차원 구조가 사라지고, 첫 층 가중치만 78,400개로 파라미터가 너무 많다(교과서 104쪽 왼쪽 두 문제점). CNN은 이미지를 2차원 그대로 받아 작은 필터를 돌려쓴다.

④ 합성곱층 = 특징 추출 (104~105쪽) — 가장 공들일 부분

이렇게 말한다
  • 필터는 3×3 숫자판 하나. 이미지 위를 한 칸씩 옮겨 다니며 겹친 칸끼리 곱해서 더한다(퍼셉트론과 같은 계산). 결과 표 한 장이 특징 맵. 필터 하나 → 맵 한 장.
  • 필터 하나는 특징 한 가지만 찾는다(필터 A 세로선, B 가로선). 그래서 한 층에 필터가 여러 개이고 맵도 여러 장 나온다.
  • 층이 깊어질수록 선 → 눈·코 → 얼굴. 교과서 105쪽의 "첫 번째 필터"는 "첫 번째 층"의 뜻(104쪽 그림은 층1·2·3).
  • 필터 값은 사람이 정하지 않는다. 가중치이므로 학습으로 정해진다(105쪽 맨 아래 상자). 104쪽 필터 A·B는 원리를 보여 주는 예시.
헷갈리는 점 교과서 그림Ⅱ-20 오른쪽 작은 네모들은 특징 맵이 아니라 "그 층의 필터가 찾는 무늬"다. 학생에게는 "각 층이 찾아내는 특징"으로만 말하면 된다. 그림Ⅱ-21의 "두 결괏값을 합친 결과"는 윤곽선 그림을 보여 주려고 합친 것이고, CNN 안에서는 필터별 맵을 합치지 않고 따로 다음 층에 넘긴다(학생 자료에 한 줄 있음).
출력 크기 한 칸씩 옮길 때 출력 = 입력 − 필터 + 1. 4×4에 3×3 → 2×2. (보폭·패딩은 교과서 밖)

⑤ 풀링층 = 줄이기 (105쪽)

이렇게 말한다 2×2 영역마다 최댓값 하나만 남긴다 → 가로·세로 절반, 칸 수 1/4. 학습할 가중치가 없다. 줄이면 ① 계산이 가벼워지고 ② 글씨가 한두 칸 밀려도 같은 결과가 나오고 ③ 다음 층 필터가 더 넓은 범위를 보게 된다.
헷갈리는 점 풀링이 합성곱층마다 붙는 것은 아니다. CNN Explainer 모델은 합성곱 두 번마다 풀링 한 번. 교과서 그림은 1+1을 한 묶음으로 그렸을 뿐, 몇 번씩 쌓을지는 설계자가 정한다.

⑥ 완전 연결층 = 분류 (105쪽)

이렇게 말한다 추출한 특징 맵들을 일렬로(1차원으로) 펼쳐 지난 시간 배운 신경망(Dense 층, 출력층 소프트맥스)에 넣어 분류한다. 지난 시간엔 입력 단계에서 펼쳤고, CNN은 특징을 다 뽑은 뒤에 펼친다. CNN = 특징 추출(합성곱+풀링) + 지난 시간 신경망(완전 연결층). 학습 방법은 같다: 순전파 → 손실함수 → 역전파로 필터 값과 가중치를 조정.

⑦ 생성형 인공지능과 GAN (106~107쪽)

이렇게 말한다 새로 만든 그림에는 비교할 정답이 없어 오차를 계산할 수 없다. GAN은 "진짜/가짜 맞히기"라는 정답 있는 문제로 바꾼다. 생성자(도둑)가 가짜를 만들고 감별자(경찰, 이진 분류 모델)가 가려낸다. 감별자의 판정이 생성자에게 고칠 방향을 준다. 번갈아 조금씩 배우다가 감별자가 반반밖에 못 가리면 종료. 쓸 때는 생성자만 쓴다. 프롬프트 = 원하는 결과가 나오게 하는 명령 문구, 구체적일수록 좋다.
헷갈리는 점 GAN은 생성형 AI의 한 방식일 뿐이다. 챗GPT·클로드는 "다음 단어 예측"(트랜스포머), 제미나이 이미지 생성은 확산 모델. 학생이 물으면 "자연어 처리 단원(114쪽~)에서 글 생성 AI를 배운다"로 넘긴다.

⑧ 레이블 (103쪽 활동 3·4번)

이렇게 말한다 레이블 = 정답으로 붙여 둔 이름표(붓꽃 품종, 손 글씨 정답 숫자, 객체 이름). 모델은 이름표가 붙은 것만 배운다. 객체 탐지 모델이 아는 80가지 목록이 곧 레이블 목록이라서, 샹들리에·거울·연필은 못 찾는다. 찾게 하려면 그 이름표를 붙인 사진으로 다시 학습시켜야 한다.

⑨ 얼굴 영상 생성과 딥페이크 (109쪽)

이렇게 말한다 교과서의 "다른 사람 또는 가상의 얼굴을 씌워 영상으로 만드는 기술"이 곧 딥페이크. 영화·복원처럼 좋은 쓰임도 있지만 동의 없이 쓰면 초상권 침해, 허위 영상은 범죄. 같은 기술이 쓰임에 따라 다르다. 가짜를 가려내는 딥페이크 탐지도 "진짜/가짜 분류 모델"이다.

데모(학생 페이지)운영 팁
RGB 색 섞기 (2장)노랑 → 검은색 → 흰색 버튼 순서로. "빛은 더할수록 밝아진다"만 짚는다.

풀링 (9장)1~4단계 버튼. 네 단계 끝나면 "4×4가 2×2로 줄었다".

4. 예상 질문과 답

Q. 필터는 누가 만들어요?
학습이. 처음엔 임의의 값, 틀릴 때마다 역전파로 조정된다. 104쪽 필터 A·B는 설명용 예시.
Q. 한 층에 필터가 왜 여러 개예요? 32, 64는 정해진 거예요?
필터 하나는 특징 한 가지만 찾아서. 개수는 지난 시간 노드 수(100, 50)처럼 설계자가 정한다. CNN Explainer는 층마다 10개.
Q. 특징 맵 30장은 어떻게 합쳐요?
합치지 않고 겹쳐 쌓아 둔다(컬러의 R·G·B 3장처럼). 다음 층 필터가 30장을 한꺼번에 보고 맵 한 장을 만든다. 맨 마지막에 전부 일렬로 펼쳐 완전 연결층에 넣는다.
Q. 풀링하면 정보가 사라지는데 괜찮아요?
"있다/없다"는 남고 정확한 위치만 버려진다. 분류에는 오히려 유리하다(글씨가 밀려도 같은 결과).
Q. 렐루는 왜 있어요?
지난 시간 활성화 함수 그대로. 필터 결과의 음수를 0으로 만들어 "이 무늬가 있다"는 신호만 남기고, 층을 쌓는 의미를 만든다(곱하고 더하기만 반복하면 층을 쌓아도 한 번 계산한 것과 같다).
Q. CNN은 DNN이랑 완전 다른 거예요?
포함 관계. 퍼셉트론 → 인공신경망 → 심층 신경망(딥러닝) 안에 지난 시간 모델(Dense만)과 CNN(합성곱·풀링 + Dense)이 둘 다 들어간다. 은닉층의 종류가 다를 뿐.
Q. 챗GPT도 GAN이에요?
아니다. 글 생성은 "다음 단어 예측" 방식. 자연어 처리 단원에서 다룬다.
Q. 객체 탐지에서 왜 건물·나무는 못 찾아요?
레이블(80가지)에 없어서. 레이블에 추가해 학습시키면 찾는다.

5. 교과서와 다르게 쓴 곳

  • 105쪽 "첫 번째 필터를 통과할 때는 경계선…" → 자료에서는 "첫 번째 합성곱층"(104쪽 그림·본문과 맞춤).
  • 103쪽 ETRI 객체 탐지 사이트가 닫혀 페이지 안에서 직접 돌아가는 객체 탐지로 대체(같은 80종). 거실 사진 대신 위키미디어 공용 CC0 사진(거리·책상) 사용.
  • 106쪽 서비스 예시(달리2·AskUp·뤼튼)는 종료·변동되어 뺌. 107쪽 함께 해결하기(이미지 생성), 108~109쪽 실습해 보기 4개, 109쪽 스스로 해결하기는 수업 시간상 뺌. 프롬프트 정의는 12장에 유지.
  • 교과서 밖 추가: 풀링층에 가중치가 없다, 필터 값은 학습으로 정해진다(105쪽 근거), 딥페이크 용어, 지난 시간 모델 파라미터 84,060개.
