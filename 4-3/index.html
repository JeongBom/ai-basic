인공지능은 산불 예방을 어떻게 할까?

202쪽
비정형 데이터로 사회 문제를 해결하기 위한 분류 프로젝트는 어떻게 수행할까?

2019년 가을 호주에서 사상 최악의 산불 사태가 발생해 약 헥타르(ha), 대한민국 국토 면적의 85%에 해당하는 대지가 타버렸습니다. 산림청의 산불 통계 데이터를 보면 해외뿐 아니라 우리나라도 산불 피해 경험이 있습니다. 2004년 4월에는 강원도 동해안 지역을 따라 산불이 발생해 피해 면적이 23,794 ha에 달했는데, 이는 서울 종로구의 10배에 해당하는 수준이었습니다. 세계 각국에서도 , 엘리뇨 등 기상 이변으로 대형 산불이 빈번히 발생해 심각한 환경 파괴가 일어나고 인명 및 재산 피해도 발생하고 있습니다.

따라서 지구 온난화에 따른 산불의 피해를 줄이기 위해서는 다양한 분야에 대한 투자와 지원이 필요하며 기후 변화에 미치는 영향을 줄이기 위해 지속적으로 노력해야 합니다.

“인공지능은 지속가능발전목표를 달성하는 데 도움을 줍니다.”

화재 예방을 위해 산불 관련 이미지 데이터를 학습하는 인공지능 모델을 제작해 본다.
비정형 데이터정해진 형식이나 구조 없이 자유롭게 저장되는 데이터. 대표적인 예로는 텍스트 데이터, 데이터, 오디오 데이터, 비디오 데이터 등이 있다. 표로 정리된 정형 데이터와 반대되는 개념이다.
프로젝트 주제 선정인공지능을 활용하여 프로젝트를 수행하는 과정에서 주제 선정은 매우 중요한 과정이다. 하지만 모둠에서 정한 주제와 관련된 데이터가 없거나 부족한 경우가 대부분이다. 그래서 이때는 SDGs 영역을 선정하고 이와 관련된 데이터를 탐색한 후 데이터를 중심으로 주제를 정할 수 있다.

프로젝트 수행 과정 산불 이미지 분류 프로젝트는 다음 7단계로 진행한다.

  1. 1 문제 정의
    주제를 선정하여 해결할 문제를 정의한다.
  2. 2 데이터 수집
    문제 해결에 필요한 이미지 데이터를 수집한다.
  3. 3 데이터 전처리
    수집한 데이터를 목적에 맞게 처리한다. 이미지 데이터셋 확인, 리스트 생성, 색상 변환
  4. 4 데이터 시각화 및 분석
    이미지 데이터를 시각화해 보고 그 의미를 분석한다.
  5. 5 알고리즘 선정
    문제 해결에 적합한 딥러닝 알고리즘을 설계한다. CNN
  6. 6 모델 학습
    선정한 알고리즘으로 학습시킨다. 모델 생성, 컴파일, 학습
  7. 7 성능 평가 및 수정
    모델의 정확도를 확인하고 새로운 이미지 데이터로 평가한다.

⑤ 알고리즘 선정

208쪽

문제 해결에 적합한 딥러닝 알고리즘을 설계해 보자.

데이터 시각화 분석 결과를 모둠원과 함께 살펴본 후 문제 해결에 적합한 딥러닝 알고리즘을 설계한다.

산불 이미지 데이터나 산불이 아닌 이미지 데이터와 같은 데이터를 분류하기 위해 합성곱 신경망(CNN: Convolutional Neural Networks, 이후 CNN) 딥러닝 모델을 활용한다.

CNN은 딥러닝에서 이미지 또는 영상 데이터를 처리할 때 사용하며 그 이름에서 알 수 있듯이 컨볼루션(convolution)이라는 연산이 들어가는 딥러닝 모델이다. 교과서는 “컨볼루션이라는 데이터 전처리 작업이 들어가는 딥러닝 모델”이라고 적었다. 컨볼루션은 학습하기 전에 하는 전처리가 아니라 모델 안에서 이루어지는 연산이다.

CNN의 주요 구성 요소는 과 으로 이미지 처리와 패턴 인식을 위한 특징을 추출할 때 핵심적인 역할을 담당한다. 컨볼루션은 입력 데이터와 필터 간의 합성곱 연산을 통해 특징을 추출하는 것이고, 풀링은 입력 데이터의 공간 크기를 줄여 중요한 정보를 보존하는 것이다.

CNN은 이미지 전체보다는 부분을 보는 것, 그리고 이미지의 한 픽셀과 주변 픽셀들의 연관성을 살리는 것이 중요합니다.

1. 컨볼루션(convolution) 2단원 105쪽 합성곱층
입력 데이터와 (커널) 간의 합성곱 연산을 통해 출력 데이터를 생성한다. 필터는 입력 데이터에 적용되어 특정 패턴이나 특징을 추출하는 역할을 한다.

5×5의 행렬로 표현된 2차원의 이미지 입력값을 3×3의 행렬로 표현된 필터(커널)를 이용하여 연산 처리를 한다. 이때 사용되는 연산 처리는 같은 크기의 두 행렬을 포개어 놓고 같은 위치에 있는 값들을 곱하여 모두 더해 주는 것이다.

🧪 해 보기 — 합성곱 계산 출력의 칸을 누르면 그 값을 계산한 입력 영역과 계산 방법이 나온다.

교과서 208쪽 그림의 출력은 2 4 2 / 3 4 3 / 2 2 2이다. 그림의 입력과 커널로 직접 계산하면 둘째 칸은 3, 넷째 칸은 2가 나와서 계산한 값을 적었다.

2. 풀링(pooling) 2단원 105쪽 풀링층
입력된 이미지를 컨볼루션 처리하였을 때, 생성된 결괏값의 크기가 너무 크기 때문에 크기를 줄이는 작업을 수행하는 것이다.
  • 대표적으로 최대 풀링(max pooling)과 평균 풀링(average pooling) 두 가지가 있다.
  • 최대 풀링이란 지정한 크기에서 만을 가져와 정리한 것이다.
  • 평균 풀링이란 지정한 크기에 존재하는 값들의 만을 가져와 정리한 것이다.
  • 오른쪽 예시에서는 4×4 크기 특정 영역에 2×2 풀링 크기를 적용하여 크기의 결괏값을 생성하였다.

🤔 위 풀링 그림에서 최대 풀링의 왼쪽 위 칸은 왜 100일까?

생각한 뒤 눌러서 답 확인
4×4 영역의 왼쪽 위 2×2 칸에 있는 값은 29, 15, 0, 100이다. 이 가운데 최댓값인 100만 가져온 것이다. 평균 풀링은 같은 방법으로 값들의 평균을 가져온다.

❶ CNN 모델 생성하기 인공지능을 제작하기 위해 라이브러리를 불러오고, CNN 모델을 제작하기 위해 Sequential 모델을 사용한다.

① 각각 3개의 합성곱층과 풀링층은 차원 데이터로 구성된다.
② Flatten 계층에서 차원 배열로 데이터를 변환한 후 마지막에 2개의 층(Dense)으로 구성된 CNN 모델을 제작한다.
③ 모델이 어떻게 구성되었는지 알아보기 위해 ( ) 함수를 사용한다.

오늘 실습에서는 이미지를 150×150 크기로 줄여서 학습한다. 교과서는 400×400 크기이다. 크기를 줄이면 계산할 값이 줄어 학습이 빨리 끝난다. 그래서 아래 실행 결과의 숫자는 교과서 209쪽과 다르다. 교과서는 400×400 크기로 학습한다. 400×400으로 하면 학습에 5~10분이 걸려서 150×150으로 줄였다.
❶ CNN 모델 생성
교과서는 첫 Conv2D 안에 input_shape = (400, 400, 3)을 적었다. 지금 코랩에서는 그렇게 쓰면 경고가 나와서 tf.keras.Input으로 따로 적었고, 학습 시간을 줄이려고 크기를 150으로 했다.
import tensorflow as tf
model = tf.keras.models.Sequential([
     tf.keras.Input(shape = (150, 150, 3)),     # 입력 이미지의 크기(교과서는 400, 400, 3)
     tf.keras.layers.Conv2D(16, (3, 3), activation = 'relu'),
     tf.keras.layers.MaxPool2D(2, 2),
     tf.keras.layers.Conv2D(32, (3, 3), activation = 'relu'),
     tf.keras.layers.MaxPool2D(2, 2),
     tf.keras.layers.Conv2D(32, (3, 3), activation = 'relu'),
     tf.keras.layers.MaxPool2D(2, 2),
     tf.keras.layers.(),
     tf.keras.layers.Dense(128, activation = 'relu'),
     tf.keras.layers.Dense(1, activation = '')
])
model.summary()
