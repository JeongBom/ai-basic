딥러닝의 구조

92쪽

인간의 뇌를 모방하여 뉴런의 역할을 하는 퍼셉트론의 수를 늘리고, 이 퍼셉트론들을 네트워크처럼 연결한 인공지능 모델을 인공신경망(ANN: Artificial Neural Network)이라고 한다.

층하는 일붓꽃 분류 모델이라면
입력층 (input layer)외부에서 입력 데이터를 받는 곳. 각 노드는 입력 신호의 특징을 나타낸다.꽃받침 길이·너비, 꽃잎 길이·너비 → 노드 4개
은닉층 (hidden layer)입력층과 출력층 사이. 입력 데이터의 복잡한 특징과 패턴을 학습한다. 겉에서 보이지 않아 ‘은닉’이라고 한다.개수와 노드 수는 사람이 정한다
출력층 (output layer)최종 결과를 내보내는 곳. 각 노드는 예측하려는 클래스나 값을 나타낸다.세토사·버시컬러·버지니카 → 노드 3개

은닉층과 퍼셉트론 수를 늘리면 더 어려운 문제를 풀 수 있다. 은닉층이 여러 개(2개 이상)인 신경망을 심층 신경망(DNN) 또는 딥러닝이라고 한다.

🎯 딥러닝의 학습이란?

예측값을 실젯값과 비교해 오차를 줄이는 방향으로 가중치와 편향을 조절하는 과정을 반복한다.

순서하는 일
데이터를 넣어 은닉층과 출력층을 거쳐 예측값을 낸다. (예측 성적 70)
예측값과 실젯값의 차이(오차)를 손실함수로 계산한다. (70 ↔ 실제 80)
오차를 줄이도록 반대 방향으로 가며 가중치와 편향을 고친다.

(3) 역전파와 경사 하강법

94쪽

오차를 계산한 뒤, 오차를 줄이도록 순전파의 반대 방향으로 이동하며 각 퍼셉트론의 가중치와 편향을 고치는 것을 역전파라고 한다.

이때 손실함수를 가장 작게 만드는 최적화 알고리즘인 경사 하강법을 사용한다.

비유로 이해하기 — 안개 낀 산에서 내려오기
앞이 보이지 않을 때는 발밑의 기울기를 느껴 가장 가파르게 내려가는 쪽으로 한 걸음씩 옮긴다. 경사 하강법도 오차가 줄어드는 방향으로 가중치를 조금씩 바꾸어 오차가 가장 작은 곳(골짜기)을 찾아간다.
직접 해 보기 — 안개 낀 산에서 골짜기로 내려가기

가로축은 가중치 w, 세로축은 오차이다. 사람이 서 있는 자리의 발밑 기울기(빨간 선)만 보고, 내리막 쪽으로 학습률 × 기울기만큼 한 걸음 옮긴다.

현재 걸음 수: 0

예시로 오차 = (w − 3)² + 1 곡선을 그렸다. 이때 기울기 = 2(w − 3), 새 w = w − 학습률 × 기울기. 기울기가 거의 0이 되면 골짜기에 도착한 것이고, 그 뒤로는 걸음을 더 옮겨도 거의 움직이지 않는다. 실제 딥러닝은 가중치가 수천~수백만 개라 골짜기도 수천 차원이지만 원리는 같다.

🤔 학습률을 ‘너무 크게’로 바꾸고 10걸음을 눌러 보자. 사람은 어떻게 될까?

생각한 뒤 눌러서 답 확인
골짜기를 건너뛰어 반대편 비탈로 가고, 걸음마다 더 멀어져 오차가 오히려 커진다. 반대로 ‘작게’는 바닥까지 너무 오래 걸린다. 학습률은 사람이 정하는 값이라 적당한 크기를 찾아야 한다.

순전파 → 오차 계산 → 역전파를 반복하다가 오차가 충분히 작아지면 학습을 끝낸다.

스스로 해결하기 — 학습 과정 정리

94쪽

입력값이 공부 시간과 집중도이고 출력값이 성적 예측일 때, 이 딥러닝 모델의 성능을 높이기 위한 학습을 정리해 보자.

단계하는 일
1. 공부 시간과 집중도 데이터를 입력하고 성적 예측값을 출력한다.
2. 모델이 예측한 성적과 실제 성적을 비교하여 오차를 계산한다.
3. 오차를 줄이도록 순전파의 반대 방향으로 이동하며 가중치를 수정한다.
4. 반복다시 새로운 데이터를 입력하여 1 → 2 → 3 단계를 반복한다.
5. 종료오차가 일정 수준 이하로 나오거나 정해진 학습 횟수를 마치면 학습을 종료한다.

인공신경망 시뮬레이터 텐서플로 플레이그라운드에서 파란 점과 주황 점을 나누는 신경망을 만들어 보자.

바꾸는 곳뜻
DATA (왼쪽)분류할 점들의 배치 모양 4가지 중 하나를 고른다.
FEATURESX₁, X₂ 두 개만 켠 상태 그대로 둔다. 다른 칸(X₁², sin(X₁) 등)을 켜면 사람이 특징을 만들어 넣는 셈이 되어, 은닉층 없이도 풀려 버린다.
HIDDEN LAYERS (+ −)은닉층의 수 (깊이)
neurons (각 층 위의 + −)그 은닉층에 들어 있는 퍼셉트론(뉴런)의 수 (폭). 층마다 따로 정한다.
▶ 버튼과 Epoch학습 시작·중지. 옆의 숫자 000,000이 학습을 반복한 횟수이다.
OUTPUT 보는 법
  • 점의 색 = 실제 정답, 배경색 = 신경망이 예측한 영역. 파란 점은 파란 배경, 주황 점은 주황 배경 위에 있으면 잘 분류한 것이다.
  • Discretize output에 체크하면 배경이 두 색으로 딱 나뉘어 경계가 잘 보인다.
  • Test loss / Training loss = 손실함수로 계산한 오차. 0에 가까울수록 잘 분류한 것이다. (0.5 근처면 거의 못 나눈 상태)
  • 옆의 작은 곡선은 학습하며 loss가 줄어드는 모습이다. 곡선이 평평해지면 더 학습해도 나아지지 않는다.

한 줄 판단법 : 점이 같은 색 배경 위에 있고, Test loss가 0에 가까우면 성공!

❶ 퍼셉트론 1개로 분류해 보기
  1. DATA: 왼쪽 위 원형(Circle) 데이터셋을 고른다.
  2. HIDDEN LAYERS: − 버튼을 눌러 0으로 만든다.
  3. Discretize output에 체크한다.
  4. ▶ 버튼으로 학습을 시작하고, OUTPUT에서 분류가 되었으면 중지한다. 분류가 안 되면 Epoch 300에서 중지한다.
  5. Epoch(학습 횟수)와 Test loss를 확인한다.

관찰 — 배경이 점의 색과 맞는가? 300번을 돌려도 Test loss가 0.5 근처에 머무는 이유는 무엇일지 친구들과 이야기해 보자.

❷ 딥러닝으로 분류해 보기
  1. HIDDEN LAYERS: + 버튼을 눌러 2개 이상 만든다.
  2. neurons: 각 층의 + 버튼으로 퍼셉트론 수를 늘린다.
  3. ▶ 버튼으로 학습을 시작한다.

관찰 — 배경 모양이 어떻게 바뀌는가? Test loss는? 어떻게 분류하였는지 친구들과 이야기해 보자.

❸ 더 복잡한 데이터 분류해 보기
  1. DATA: 오른쪽 아래 나선형(Spiral) 데이터셋을 고른다.
  2. 은닉층 수와 은닉층별 퍼셉트론 수를 조절한다.
  3. ▶ 버튼으로 학습을 시작하고, Test loss가 0에 가까워지면 중지한다.

관찰 — 분류에 걸린 Epoch는? 학습 횟수가 가장 적은 친구의 모델에 대해 이야기해 보자.

🤔 ❶ 은닉층이 0개(퍼셉트론 1개)면 왜 원형 데이터를 제대로 나누지 못할까?

생각한 뒤 눌러서 답 확인
단층 퍼셉트론은 직선 하나로만 영역을 나눌 수 있다. 원 모양처럼 직선 하나로 나눌 수 없는 데이터는 분류하지 못한다.

🤔 ❷ 은닉층을 2개 이상 만들면 어떻게 될까?

생각한 뒤 눌러서 답 확인
퍼셉트론을 여러 층으로 연결하면 원래 공간을 새로운 특징 공간으로 바꿀 수 있어서 원 모양으로 잘 나눈다.

확인 문제

91~95쪽

모든 문제의 답을 고른 뒤 채점하기를 누르세요.

1. 퍼셉트론의 구성 요소가 아닌 것은?

퍼셉트론은 가중치, 편향, 활성화 함수로 이루어져 있다.

2. 입력 1, 2 / 가중치 3, 4 / 편향 5일 때 가중합은?

(1×3) + (2×4) + 5 = 16

3. 은닉층이 여러 개인 신경망을 무엇이라고 할까?

은닉층이 2개 이상이면 딥러닝(DNN)이다.

4. 다중 분류 모델의 출력층에서 주로 쓰는 활성화 함수는?

소프트맥스는 출력의 합이 1이 되게 바꿔 확률로 해석할 수 있게 한다.

5. 딥러닝 학습의 순서로 알맞은 것은?

데이터를 넣어 예측하고(순전파), 오차를 계산한 뒤, 거꾸로 가며 가중치를 고친다(역전파).

6. 예측 모델에서 주로 쓰는 손실함수는?

예측(회귀) 모델은 MSE를 쓴다.

정리

90~95쪽
퍼셉트론입력 × 가중치의 합 + 편향 → 활성화 함수 → 출력. 가중치와 편향은 학습으로 정한다.
딥러닝의 구조입력층 → 은닉층 → 출력층. 은닉층이 여러 개면 딥러닝(심층 신경망)
활성화 함수은닉층: 렐루 / 출력층: 이진 분류 시그모이드, 다중 분류 소프트맥스, 예측은 사용하지 않음
딥러닝의 학습순전파 → 오차 계산(손실함수) → 역전파(경사 하강법)를 반복
